About this dashboard. Built from the vendor security assessment questionnaire and cost analysis; statuses for the 31 actionable items come from the internal task tracker's "Open Items" tab, the remaining 42 items are marked "No action required" / "Not applicable" in the source questionnaire and start as Completed. Status changes, added items, and imports live only in this open view — this is a self-contained page with no server or browser storage, so use Export progress to save a full snapshot (JSON, including any items you've added) and Import progress to reload it (e.g. in a fresh copy of this dashboard) later. Use + Add item to add a new row to the tracker.
